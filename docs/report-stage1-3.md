# Отчёт: Eww Island — этапы 1–3 (30 ноября 2026)

## 1. Этап: надёжность скриптов

### Что изменено

- **`scripts/run-island.sh`** переписан: демон через `timeout` + фон, геометрия через
  `island-geom.sh`, монитор по координатам окна, центрирование с проверкой и
  восстановлением. Ненулевой код — только при реальной ошибке (демон не поднялся,
  окно не появилось, ширина не измерена).

- **`scripts/build-eww.sh`** переписан: убран `git checkout --`, вместо него
  идемпотентное применение патчей: `git apply --reverse --check` (уже применён →
  откат и накат) → `git apply --check` → `git apply`. При конфликте — диагностика
  в stderr, ненулевой код, файл не тронут. Чужие правки в других файлах
  переживают пересборку.

- **`adapters/x11/island-geom.sh`** — новый скрипт поиска окна острова: PID демона +
  тип `_NET_WM_WINDOW_TYPE_DOCK`. XID сравниваются как числа.

- **Ограничение Eww** (не обійдено молча): `eww daemon` при занятом сокете виснет
  вечно (родитель ждёт IPC-ответа, `client::do_server_call` читает до упора). Обход
  в скрипте: запуск демона в фоне под `timeout` + проверка готовности `ping` тоже
  под `timeout`.
