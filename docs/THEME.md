# Темы: схемы, роли, применение

Шаг 08 задания (шаг 1 тем). Внешний вид при `default` не меняется: цвета
перенесены 1:1, проверено замером пикселей.

## Структура

```
theme/
  schemes/default.json        схема по умолчанию (роли и значения)
  templates/colors.scss.tpl   шаблон eww/colors.scss
  templates/assets/*.svg      шаблоны SVG с плейсхолдерами {{роль}}
  apply.sh                    рендер схемы в eww/colors.scss и eww/assets/
eww/
  colors.scss                 GENERATED, не править
  assets/*.svg                GENERATED, не править (23 файла)
  eww.scss                    подключает colors.scss через @import "colors"
```

## Роли

`theme/schemes/default.json` содержит три блока.

**colors** - непрозрачные роли, значение `#rrggbb`:

| роль | значение default | роль в интерфейсе |
|---|---|---|
| `surface` | `#141414` | тело острова, тело панелей, заливка углов |
| `surface_container` | `#1c1e22` | карточки и чипы внутри поверхностей |
| `surface_high` | `#25282e` | hover/selected контейнер |
| `surface_highest` | `#2b2f36` | жёлоба ползунков, вложенные плашки |
| `outline` | `#2e3138` | границы, неактивные иконки Wi-Fi |
| `on_surface` | `#e6e8ec` | основной текст (часы, температура) |
| `on_surface_variant` | `#9aa0a6` | вторичный текст, подписи |
| `primary` | `#4fc3f7` | акцент, активная вкладка, иконки |
| `primary_dim` | `#2a6e8f` | приглушённый акцент, выбранный день |
| `error` | `#f2b8b5` | ошибки |
| `on_primary` | `#ffffff` | текст на акцентной плашке |
| `weather_cloud` | `#90a4ae` | облака в иконках `cond-*` |
| `weather_snow` | `#b0bec5` | снег в иконках `cond-*` |

**alphas** - полупрозрачные роли. Хранятся как цвет + alpha отдельно, а не
готовой строкой `rgba()`: так схема остаётся набором цветов, а alpha можно
менять независимо. `apply.sh` собирает `rgba(r, g, b, a)`. В поле `color`
допустимо имя роли (`primary`) или литерал (`#ffffff`, `#000000`).

| роль | цвет | alpha | что это |
|---|---|---|---|
| `state_hover` | `#ffffff` | 0.08 | слой наведения |
| `state_press` | `#ffffff` | 0.12 | слой нажатия |
| `state_selected` | `primary` | 0.14 | слой выбора |
| `divider` | `#ffffff` | 0.08 | разделители |
| `on_surface_dim` | `on_surface` | 0.32 | дни вне месяца в календаре |
| `text_shadow` | `#000000` | 0.75 | тень текста карточки погоды |
| `wx_shade` | `#000000` | 0.35 | запасное затемнение фона (класс) |
| `wx_scrim` | `#000000` | 0.45 | боковое затемнение слева в карточке |
| `wx_ink` | `#000000` | 1 | база для `rgba()` с alpha из `w-shade` |

**weather_gradients** - запасные CSS-градиенты верхней карточки погоды
(`$wx-clear-day-a` и т.д.). В обычной работе их не видно: inline-стиль с
JPEG-сценой перекрывает `background-image` класса. В схеме перечислены,
чтобы цвета не искать по файлу.

## Как применить схему

```sh
theme/apply.sh default            # только перегенерировать файлы
theme/apply.sh default --reload   # плюс eww reload
```

Скрипт идемпотентный: повторный запуск с той же схемой даёт те же файлы,
`git status` остаётся чистым. Разрешён только `sh` и `python3`, ничего не
устанавливается.

## Как добавить схему

1. Скопировать `theme/schemes/default.json` в `theme/schemes/<имя>.json`.
2. Поменять `name` (по нему же подставляется `// Scheme:` в colors.scss)
   и нужные значения. Ключи не переименовывать: шаблоны ссылаются на них.
3. `theme/apply.sh <имя> --reload`.
4. Сгенерированные `eww/colors.scss` и `eww/assets/*.svg` закоммитить.

Проверять глазами обязательно: ошибка в SCSS роняет весь стиль на тему GTK
молча, без сообщения в логе. Надёжный признак - замер пикселя
(`import -window root -crop 1x1+X+Y +repage txt:-`): правильный default даёт
тело острова `20,20,20`, плашку активной вкладки `79,195,247`.

## Что генерируется и почему именно так

- `eww/colors.scss` собирается из `templates/colors.scss.tpl`. Файл только
  ASCII: SCSS-компилятор добавляет `@charset` на не-ASCII входе, а GTK
  отбрасывает такое правило целиком вместе со всем стилем.
- SVG собираются из `templates/assets/`. В шаблонах плейсхолдеры вида
  `{{primary}}` в атрибутах `fill`/`stroke`. Генерация default совпадает с
  прежними файлами байт-в-байт (23 файла, 0 различий).
- `eww/eww.scss` подключает цвета строкой `@import "colors";`. Компилятор
  нашей сборки (grass 0.13.4) ищет импорт относительно каталога конфига,
  поэтому путь короткий. Проверено: проба с импортированным цветом
  отрисовалась именно им.
- Inline-стиль карточки погоды использует `:css`, а не `:style`: `:style`
  оборачивает содержимое в `* { ... }`, и `@import` внутри не компилируется.
  В `:css` путь абсолютный: `@import "${EWW_CONFIG_DIR}/colors.scss";`.

## Что НЕ в этом шаге

Иллюстрации погоды (JPEG-сцены `wx-bg-*.jpg`) не перекрашиваются схемой,
они лежат как есть. Старые градиентные `wx-bg-*.svg` остались в репозитории,
но нигде не используются (карточка берёт JPEG). Plank, Ulauncher, обои и
схемы Noctalia не затрагиваются.
