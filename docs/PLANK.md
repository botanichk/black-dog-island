# Док Plank в стиль острова

Plank повторяет остров: заливка — `$surface` острова, рамка — `$primary`,
скругления — `$r-surface` (18 px). Отличие одно: заливка чуть просвечивает,
чтобы док не выглядел глухим пятном на светлых обоях.

Сменил палитру, акцент или обои — док перекрасился вместе с островом,
отдельной настройки нет.

## Как это устроено

```
theme/apply.sh                 рендерит eww/colors.scss ($surface, $primary)
  -> theme/plank.sh apply      берёт цвета, соберёт тему, перезапустит Plank
  -> ~/.local/share/plank/themes/EwwIsland/dock.theme
  -> dconf /net/launchpad/plank/docks/dock1/theme = 'EwwIsland'
```

`theme/plank.sh` вызывается из `theme/apply.sh` последним шагом, поэтому
работает при любом способе смены темы: вкладка «Цвета», смена акцента,
переключение режима, схема «С обоев» и хук выбора обоев. Если `plank.sh`
отсутствует или упал, `apply.sh` продолжает работу — остров не должен
зависеть от дока.

## Что меняется, а что нет

`EwwIsland` — **полная копия** исходной темы, в которой заменены только
строки вида:

| Строка | Значение | Откуда |
|---|---|---|
| `FillStartColor` / `FillEndColor` | `$surface` с альфой `FILL_ALPHA` (230) | поверхность острова |
| `OuterStrokeColor` | `$primary` с альфой 200 | акцент острова |
| `InnerStrokeColor` | `$surface` с альфой 0 | у острова внутренней обводки нет |
| `TopRoundness` / `BottomRoundness` | 18 | `$r-surface` острова |

Остальное (`LineWidth`, отступы, размеры индикаторов, тайминги) — как в
исходной теме. Своя тема, а не правка твоей: правка в `Tokyonight-Storm-B`
затёрлась бы при обновлении набора.

Исходная тема запоминается в `~/.config/eww-island/plank-base-theme` при
первом запуске. Она не в git: это состояние конкретной машины.

## Прозрачность

`FILL_ALPHA` в `theme/plank.sh` — 230 из 255, около 90 %. Обои под доком
угадываются, но контраст иконок и подписей не страдает.

Проверено замерами на этой машине: при альфе 255 в полосе дока 11775
пикселей ровно `#fce0cf` (`$surface` без примесей), при 230 — только 227,
остальное смешано с фоном. То есть прозрачность действительно применяется,
а не игнорируется.

## Почему Plank перезапускается

Plank **не перечитывает** `dock.theme` на лету. Проверено: смена темы через
dconf при работающем процессе не меняет ни одного пикселя, а после
`pkill -x plank` + запуска тема появляется.

Перезапуск занимает ~1 секунду, поэтому окно дока на миг исчезает. Это
цена решения; при быстром переборе палитр док мигнёт столько же раз.

Если набор строк вида не изменился и Plank уже работает, перезапуска нет.
Проверка «Plank работает» в этом условии обязательна — без неё закрытый док
так и оставался закрытым (было поймано на проверке).

## Команды

```sh
theme/plank.sh apply     # подтянуть тему (это же делает apply.sh)
theme/plank.sh status    # тема, исходная тема, рамка, заливка, радиусы, жив ли Plank
theme/plank.sh restore   # вернуть исходную тему, нашу убрать
```

`restore` возвращает `dconf` на исходную тему, удаляет `EwwIsland` и файл
состояния. Повторный `restore` отвечает «нечего возвращать» и выходит с
кодом 1.

## Как проверить

Док по умолчанию в режиме `intelligent` (скрыт, пока не ткнуть мышью),
поэтому для замера его надо показать. Владелец просил не дёргать рабочий
стол — на время замера переключение `hide-mode` обратимо:

```sh
ORIG=$(dconf read /net/launchpad/plank/docks/dock1/hide-mode)
dconf write /net/launchpad/plank/docks/dock1/hide-mode "'none'"; sleep 5
import -window root -crop 1366x108+0+660 +repage /tmp/p.png
dconf write /net/launchpad/plank/docks/dock1/hide-mode "$ORIG"
```

Замеры на этой машине (док `1366x108+0+660`, исходная тема
`Tokyonight-Storm-B`, `$surface=#fce0cf`, `$primary=#aa480b`):

| Что | Ожидание | На экране |
|---|---|---|
| заливка (альфа 255) | `#fce0cf` | 11775 px ровно `#fce0cf` |
| заливка (альфа 230) | смесь с фоном | 227 px чистого, остальное смешано |
| рамка | `$primary` × 200/255 | `#bb6835` (ожидание `#bc6935`) |
| заливка по высоте | весь док | y 40…107 |
| рамка | по контуру | 1617 px, y 40…107 |

Скругление видно по левому краю заливки: y=40 начинается с x=220, дальше
уходит влево до x=282 — это дуга радиуса 18.

## Ограничения

- Нужны `plank`, `dconf`, `gsettings`, `wmctrl`, `pgrep`/`pkill` — всё из
  системы.
- Если сменить тему Plank вручную (через `plank --preferences`), наша
  `EwwIsland` перестанет показываться, и `apply.sh` вернёт её при следующей
  смене палитры. Исходная тема при этом не потеряется: она в state-файле.
- Прозрачность заливки работает благодаря композитингу xfwm4
  (`/general/use_compositing = true`). Если его выключить, док станет
  непрозрачным — это ограничение X11, а не темы.
