# Рамка Plank в цвет акцента острова

Док Plank берёт цвет своей рамки из `$primary` — того же цвета, что
подсвечивает активные элементы острова. Сменил палитру, акцент или обои —
рамка перекрасилась вместе с островом, отдельной настройки нет.

## Как это устроено

```
theme/apply.sh                 рендерит eww/colors.scss ($primary)
  -> theme/plank.sh apply      берёт $primary, соберёт тему, перезапустит Plank
  -> ~/.local/share/plank/themes/EwwIsland/dock.theme
  -> dconf /net/launchpad/plank/docks/dock1/theme = 'EwwIsland'
```

`theme/plank.sh` вызывается из `theme/apply.sh` последним шагом, поэтому
работает при любом способе смены темы: вкладка «Цвета», смена акцента,
переключение режима, схема «С обоев» и хук выбора обоев. Если `plank.sh`
отсутствует или упал, `apply.sh` продолжает работу — остров не должен
зависеть от дока.

## Что меняется, а что нет

`EwwIsland` — **полная копия** исходной темы, в которой изменена ровно одна
строка, `OuterStrokeColor`. Заливка (`FillStartColor`/`FillEndColor`),
скругления, отступы, толщина линии, прозрачность рамки — всё как в исходной
теме. Своя тема, а не правка твоей: правка в `Tokyonight-Storm-B` затёрлась
бы при обновлении набора.

Исходная тема запоминается в `~/.config/eww-island/plank-base-theme` при
первом запуске. Она не в git: это состояние конкретной машины.

## Почему Plank перезапускается

Plank **не перечитывает** `dock.theme` на лету. Проверено: смена темы через
dconf при работающем процессе не меняет ни одного пикселя рамки (только
тултип перерисовался), а после `pkill -x plank` + запуска рамка появляется —
оранжевая `Catppuccin-Mocha-B` дала 4183 пикселя по контуру.

Перезапуск занимает ~1 секунду, поэтому окно дока на миг исчезает. Это
цена решения; при быстром переборе палитр док мигнёт столько же раз.

Если цвет не изменился и Plank уже работает, перезапуска нет: повторный
`theme/plank.sh apply` занимает 0,08 с. Проверка «Plank работает» в этом
условии обязательна — без неё закрытый док так и оставался закрытым
(было поймано на проверке).

## Команды

```sh
theme/plank.sh apply     # подтянуть рамку (это же делает apply.sh)
theme/plank.sh status    # тема, исходная тема, цвет рамки, жив ли Plank
theme/plank.sh restore   # вернуть исходную тему, нашу убрать
```

`restore` возвращает `dconf` на исходную тему, удаляет `EwwIsland` и файл
состояния. Повторный `restore` отвечает «нечего возвращать» и выходит с
кодом 1.

## Как проверить

Пиксели: у рамки альфа 200 из 255, поэтому на экране цвет не равен `$primary`,
а смешан с фоном под доком.

```sh
grep -m1 '^\$primary:' eww/colors.scss      # например #9bfece
theme/plank.sh status                        # рамка: 155;;254;;206;;200
import -window root /tmp/p.png
# ожидаемый цвет на экране = round(c * 200/255 + 10 * 55/255)
```

Замеры на этой машине (док `1366x108+0+660`, тема `Tokyonight-Storm-B`):

| `$primary` | в теме | на экране | пикселей |
|---|---|---|---|
| `#9bfece` (Noctalia, светлый акцент) | `155;;254;;206;;200` | `#7cc9a4` | 363 |
| `#39bae6` (Ayu) | `57;;186;;230;;200` | `#2f94b6` | 361 |

Рамка идёт по контуру дока: верхняя кромка 298 px в ряд, боковые по 2 px
(так Plank рисует при `position=bottom`), низ у края экрана не рисуется.

## Ограничения

- Только рамка. Заливка дока намеренно не трогается — так просил владелец.
- Нужны `plank`, `dconf`, `gsettings`, `wmctrl`, `pgrep`/`pkill` — всё из
  системы.
- Если сменить тему Plank вручную (через `plank --preferences`), наша
  `EwwIsland` перестанет показываться, и `apply.sh` вернёт её при следующей
  смене палитры. Исходная тема при этом не потеряется: она в state-файле.
- `LineWidth=2` из темы `Tokyonight-Storm-B` при рамке такого цвета даёт
  тонкую линию; если хочется заметнее, это правится в исходной теме, а не
  здесь.
