# Спека: единая панель-хаб (этап 6)
Порядок шагов важен. Делать по одному, брать в работу только тот шаг,
который назвал владелец. Один шаг - один коммит.

## Статус
- Шаг 0 (ширина острова 619 константа): СДЕЛАНО.
- Шаг 1 (каркас хаба: календарь, погода, Wi-Fi): СДЕЛАНО.
- Шаг 2 (оформление колонки, плашка $primary): СДЕЛАНО.
- Автоскрытие только для полноэкранных окон: в работе (отдельное задание).
- Шаг 2б (карточки погоды): НЕ СДЕЛАНО.
- Шаг 3 (вкладка "Снимок"): НЕ СДЕЛАНО.
- Шаг 4 (кнопка обоев на острове): НЕ СДЕЛАНО.
Дальше по ROADMAP.md: Wi-Fi с управлением, вкладки система/звук/Bluetooth.

## Общие законы (не менять)
- Остров: 373,0, 619x50. Хаб: x и ширина как у острова, y=50, одна высота
  для всех вкладок. Заголовок окна хаба начинается с "Eww - panel-".
- Каждая вкладка заполняет область справа от колонки вкладок по ширине и
  высоте, отступы одним классом .hub-tab. Размер окна от вкладки не зависит.
- Иконки вкладок и кнопок: символы Meslo Nerd Font в label, цвет из CSS.
- Цвета и радиусы только из переменных SCSS. Не менять стык с островом.

## Шаг 2б. Карточки погоды
1. Нижняя карточка (4 показателя: ощущается, ветер, влажность, восход/закат)
   по высоте содержимого (:vexpand false, :valign "end").
2. Верхняя карточка забирает оставшуюся высоту (:vexpand true): под неё потом
   идут фоны.
3. Фон верхней карточки зависит от погоды: класс из переменной (`wx_kind`),
   у каждого вида правило в eww.scss: ясно, облачно, дождь, снег, туман, гроза,
   день и ночь. Скрипт adapters/weather/forecast.sh отдаёт вид и признак
   день/ночь (если ещё нет).
4. Сначала CSS-градиенты, поверх них затемнение для читаемости текста
   (`linear-gradient(rgba(0,0,0,.35), rgba(0,0,0,.35))`). Картинки в
   eww/assets/weather/ (JPEG до 700x300, до 150 КБ каждая) только по решению
   владельца, с проверкой лицензии.
5. Если GTK3 не применил background-size или несколько слоёв, сказать прямо.

## Шаг 3. Вкладка "Снимок"
Скриншоты без архаичного диалога XFCE. Пакеты не ставить: используем `import`
(ImageMagick, уже установлен).
1. adapters/x11/screenshot.sh area|screen [задержка]:
   - сначала закрыть хаб (иначе он попадёт в кадр), пауза 0.4 с;
   - затем пауза на выбранную задержку (0, 3 или 5 с);
   - screen: `import -window root файл`; area: `import файл`
     (рамка мышью, клик по окну снимает окно);
   - файл ~/Pictures/Screenshots/YYYY-MM-DD_HH-MM-SS.png (время из date),
     папку создать при необходимости;
   - обновить миниатюру последнего снимка (160 px) в
     ~/.cache/eww-island/thumbs/last.png.
2. Вкладка в stack и кнопка в колонке вкладок: три кнопки "Область", "Окно",
   "Весь экран" (окно и область = один вызов import, подписи разные),
   переключатель задержки 0/3/5 с (defvar shot_delay), миниатюра последнего
   снимка, кнопки "Открыть" (xdg-open) и "Папка".
3. Копирование в буфер: только если установлен xclip (`command -v`), иначе
   пропустить и написать в отчёте. Не ставить без разрешения.
4. Если снимок под композитингом даёт чёрный кадр, сказать прямо и предложить
   запасной вариант: xfce4-screenshooter с флагами -r / -w / -f и -s.
5. Проверка текстом: файл создан, размер больше нуля, `identify` показывает
   размеры. Владельцу проверить глазами: хаба на снимке нет.

## Шаг 4. Кнопка обоев на острове
1. Проверить без установки (`command -v`): xfdesktop-settings, nitrogen,
   waypaper, variety, feh. Рабочий стол рисует xfdesktop, поэтому нужна
   утилита, которая ставит обои через xfconf. xfdesktop-settings подходит точно.
2. По умолчанию кнопка запускает xfdesktop-settings (архаично, но без новых
   зависимостей). Другую утилиту ставить только с разрешения владельца;
   команда запуска лежит в одном месте.
3. Кнопка на острове: иконка Nerd Font, стиль и hover как у соседних, ширина
   острова остаётся 619 (место берётся из растяжки).
4. Запуск не плодит копии: если окно уже открыто, поднять его (`wmctrl -a`).

## Приёмка каждого шага
1. Ответ `eww --config eww reload` без ошибок разбора; живой лог не пишется,
   пустой eww logs ничего не доказывает.
2. `wmctrl -lG | grep 'Eww - '` до и после: остров 373 0 619x50, хаб 373 50 619xH,
   одинаковые x и ширина.
3. Закрытие хаба кликом вне окна работает, стык без ступенек.
4. Раскладка, трей, прокрутка воркспейсов, громкость колесом работают как раньше.
5. Отчёт: только реально запущенное, с выводом команд, "владельцу проверить
   глазами: ..." для визуальных вещей. Один шаг - один коммит.
