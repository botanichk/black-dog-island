# Дорожная карта Eww Island (обновляется владельцем)

## Сделано
- Остров: воркспейсы (прокрутка колесом), трей (systray), раскладка, часы, батарея.
  Ширина константа 619 px, x=373, резерв сверху 50 px.
- Единый хаб panel-hub с колонкой вкладок: календарь, погода, Wi-Fi (список).
  Старые отдельные панели удалены. Вкладки заполняют окно, стык ровный.
- Контекстное меню трея увеличено. Лог чистится при старте нового демона.

## Дальше, по порядку (одна задача, один коммит)
1. Автоскрытие только для полноэкранных окон (игры, фильмы).
2. Карточки погоды: нижняя по содержимому, верхняя растягивается; фоны по погоде
   (сначала CSS-градиенты, потом, возможно, картинки 700x300 в eww/assets/weather/).
3. Вкладка "Снимок": screenshot.sh на `import`, три режима, задержка, миниатюра.
4. Кнопка обоев на острове (внешняя утилита, по умолчанию xfdesktop-settings).
5. Wi-Fi с управлением: выключатель, обновление, пароль для новых сетей, отключение.
6. Вкладки: система (EWW_CPU/RAM/TEMPS/BATTERY), звук (pactl), Bluetooth, яркость.
7. Центр управления, миниатюры обоев в хабе.
8. Косметика: hover трея (патч), анимация открытия (revealer), отдельная иконка Лесты.

## Известные ограничения
- Живой лог Eww не пишется: пустой `eww logs` ничего не доказывает (см. AGENTS.md).
- GTK3 CSS: нет keyframes, grid, flex, backdrop-filter, clip-path.
- Модель агента не принимает изображения: проверка только текстом.
