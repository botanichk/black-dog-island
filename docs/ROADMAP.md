# Дорожная карта Eww Island (обновляется владельцем)

## Сделано
- Остров: воркспейсы (прокрутка колесом), трей (systray), раскладка, часы, батарея.
  Ширина константа 619 px, x=373, резерв сверху 50 px.
- Единый хаб panel-hub с колонкой вкладок: главная, календарь, погода, Wi-Fi (список), снимок.
  Старые отдельные панели удалены. Вкладки заполняют окно, стык ровный.
- Контекстное меню трея увеличено. Лог чистится при старте нового демона.
- Автоскрытие только для полноэкранных окон (eww close/open).
- Карточки погоды: нижняя по содержимому, верхняя растягивается, фон по погоде (8 видов).
  Верхняя карточка: без иконки, текст столбцом в левом верхнем углу, белый, боковое затемнение.
- Вкладка "Снимок": три режима, задержка, миниатюра, копирование в буфер.
- Кнопка обоев (xfdesktop-settings без копий окна).
- Вкладка "Главная": плитки Wi-Fi/Bluetooth/Звук, ползунки громкости и яркости,
  блок системы (CPU/RAM/температура/батарея). Кнопка "Главная" на острове
  перед раскладкой, подсветка пока хаб на главной.

## Дальше, по порядку (одна задача, один коммит)
1. Wi-Fi с управлением: выключатель, обновление, пароль для новых сетей, отключение.
2. Центр управления, миниатюры обоев в хабе.
3. Косметика: hover трея (патч), анимация открытия (revealer), отдельная иконка Лесты.

## Известные ограничения
- Живой лог Eww не пишется: пустой `eww logs` ничего не доказывает (см. AGENTS.md).
- GTK3 CSS: нет keyframes, grid, flex, backdrop-filter, clip-path.
- Модель агента не принимает изображения: проверка только текстом.
- Батарея BAT0 на этой машине отдаёт нули (capacity=0, износ 9810 циклов):
  полоска в "Главной" показывает 0 %, это не ошибка кода.
- Резерв трея 140 px: остров держит 619 px до 9 иконок, с 10-й расширяется.
  Кнопка "Главная" отнимает запас примерно в одну-две иконки.
