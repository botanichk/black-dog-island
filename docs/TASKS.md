## Решения владельца (не менять без его слова)
- Ширина острова 619 px константа, x=373, высота 50, резерв сверху 50 px.
- Вкладок хаба ровно 7, колонка не прокручивается.
- Автоскрытие острова только для полноэкранных окон (игры, фильмы).
- Wi-Fi, Bluetooth и сеть на реальной системе при тестах не выключать.
- Название Black Dog Island применяем только при публикации на GitHub, пока Eww Island.
- Картинки агент не смотрит: проверка только цифрами, остальное "владельцу проверить глазами".
- Один шаг, один коммит. Спеки пишет только по слову владельца.

## Сделано
- Остров, воркспейсы с прокруткой, трей, раскладка, часы, громкость, автоскрытие.
- Хаб: Главная, Медиа, Календарь, Погода, Wi-Fi, Снимок, Цвета. Фоны погоды (16 иллюстраций).
- Темы: палитры Noctalia, светлая схема, цвета с обоев, Plank берёт цвет рамки из primary.
- Обои шестиугольниками (hypr-wallpicker, хук под XFCE). Чистка мёртвого кода. Отчёт REPORT-2026-11-18.
- Кнопки острова по центру высоты: углы стали слоем overlay, тело на всю высоту
  окна, плашки 9..40 при центре окна 24.5 (коммит 3642a1d).
- Нижние углы острова прямые сразу при клике по хабу: hub_opening, 164 мс вместо
  3029 мс; таймаут кнопок хаба 3s -> 8s (коммит b148eb1).
