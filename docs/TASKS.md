## Решения владельца (не менять без его слова)
- Ширина острова 619 px константа, x=373, высота 50, резерв сверху 50 px.
- Вкладок хаба ровно 7, колонка не прокручивается.
- Автоскрытие острова только для полноэкранных окон (игры, фильмы).
- Wi-Fi, Bluetooth и сеть на реальной системе при тестах не выключать.
- Название Black Dog Island применяем только при публикации на GitHub, пока Eww Island.
- Картинки агент не смотрит: проверка только цифрами, остальное "владельцу проверить глазами".
- Один шаг, один коммит. Спеки пишет только по слову владельца.
- Установщик BDI делает всё сам, включая отключение панели XFCE и автозапуск.
  Откат двухуровневый: архив настроек + журнал изменений. Поддерживаются и
  чистый, и уже настроенный XFCE. Цель - «взял и установил».
- BDI - отдельный репозиторий. Код Eww не копируется: берётся по закреплённому
  коммиту, наши правки - только через patches/*.patch. Встроенные палитры
  Noctalia лежат в репозитории, сама Noctalia есть на целевых машинах.
- Целевые системы BDI: CachyOS и Void Linux.
- Установщик - личный, без раздувания (2026-11-20): делаем только check,
  install (пакеты, сборка Eww, панель XFCE, автозапуск), резервную копию и
  uninstall по журналу. `report`, `doctor`, `doctor --deep`, доказательства
  хэшами и дампами xfconf, `features` и матрица возможностей - не делаем.
- Тесты установщика изолированы: своя шина D-Bus, пустые XDG, HOME в /tmp.
  Реальные Plank, xfconf, dconf не трогаются (правило в AGENTS.md).
- Поддерживаемый сеанс - X11 + XFCE. Остальные сеансы (Wayland, Hyprland)
  установщик, остров и автозапуск не трогают: печатают сообщение и выходят.
  `check` читает в любом сеансе, `uninstall` разрешён в любом сеансе и без X.
- Запасной выход: если панель XFCE отключена, а остров не запустился, откат
  делается из другого сеанса (Hyprland) или текстовой консоли.
