# Установка Black Dog Island

Инструкция для новичка: от пустого терминала до острова на экране.
Всё, что делает `install.sh`, можно откатить — он ведёт журнал изменений
и делает резервную копию настроек.

## 1. Что нужно заранее

- **Система:** Arch / CachyOS / Manjaro или Void Linux. Другие не поддержаны.
- **Рабочий стол:** Xfce в сеансе X11. Не Wayland: остров сделан под X11.
- **Терминал:** открой меню приложений и набери «Терминал» (или `Ctrl+Alt+T`).
- **Интернет:** сборка движка качает исходники с GitHub.

## 2. Скачать репозиторий

```
git clone https://github.com/botanichk/black-dog-island
cd black-dog-island
```

Если `git` не установлен, `check` на шаге 3 скажет, каким пакетом это лечится.
Можно и без git: на странице репозитория зелёная кнопка `Code` →
`Download ZIP`, распаковать в домашний каталог, зайти в папку в терминале.

## 3. Проверить, чего не хватает

```
./install.sh check
```

Эта команда **только читает**. Она ничего не устанавливает, не меняет и
не просит пароль. В конце печатает готовую команду для тех пакетов, которых
нет, — например на Void:

```
Поставь недостающие пакеты сам (sudo есть только у тебя):

  sudo xbps-install -S brightnessctl ImageMagick libpulseaudio NetworkManager

По желанию (не обязательно для работы острова):

  sudo xbps-install -S ulauncher
```

## 4. Поставить пакеты

Скопируй строку `sudo ...` из вывода `check` в терминал и нажми Enter.
Пароль спросит система, ввод не отображается — это нормально.

Почему это делает человек, а не скрипт: `sudo` есть только у владельца
машины, и установщик никогда не берёт его сам.

Если `check` ничего не нашёл — этот шаг пропускается.

## 5. Установить

```
./install.sh install
```

Скрипт покажет список того, что собирается сделать, и спросит `Продолжаем? [д/н]`.
Ответ `д`, дальше он по порядку:

1. **Резервная копия** настроек в `~/.local/state/bdi/backup-<дата>/`
   (каталоги Xfce, Plank, Ulauncher и дамп нужных каналов xfconf).
2. **Сборка движка** с нашими патчами. Это долго: 10–25 минут и около 2 ГБ
   в `build/`. Прогресс идёт строками с отступом, терминал закрывать нельзя.
   Повторный запуск не пересобирает, если движок уже готов.
3. **Отключение панели Xfce** — она просто перестаёт запускаться.
   Настройки панели не удаляются.
4. **Автозапуск** — `~/.config/autostart/bdi.desktop`, чтобы остров
   поднимался при входе.
5. **Запуск** острова прямо сейчас, без перезагрузки.

Каждое изменение записывается в `~/.local/state/bdi/changes.log` — по нему
потом можно вернуть прежнее состояние.

## 6. Проверить глазами

- Вверху по центру появился остров 619×50, панели Xfce снизу-сверху нет.
- Клик по кнопкам открывает хаб с семью вкладками.
- После перезагрузки остров на месте.

Если остров не появился, терминал покажет `ошибка:` с причиной.
Лог движка: `build/target/release/eww --config eww logs`.

## Как это устроено внутри

- Пакеты — по таблицам `deps/arch.txt` и `deps/void.txt`. Формат общий,
  поэтому проверка одна на все системы: `check` ищет **команду**
  (`command -v nmcli`), а не пакет с определённым именем — имена у Arch и
  Void разные, а команда одна. Пакет в таблице нужен только для печати
  команды установки.
- Движок Eww не лежит в репозитории: он клонируется в `build/eww-src`
  на закреплённый коммит из `deps/engine.txt`, затем `scripts/build-eww.sh`
  накладывает патчи из `patches/`.
- Состояние (выбор темы, схемы, кэш) живёт вне репозитория: `~/.config/bdi`,
  `~/.local/state/bdi`, `~/.cache/bdi`. Переменные `BDI_CONFIG`,
  `BDI_STATE`, `BDI_CACHE`.

## Откат

Пока вручную: журнал и резервная копия на месте, но команда `uninstall`
ещё не написана (следующий шаг). Вернуть панель Xfce можно так:

```
xfconf-query -c xfce4-session -p /sessions/Failsafe/Client2_Command -n -t string -s xfce4-panel
xfce4-panel &
rm ~/.config/autostart/bdi.desktop
```

Прежние значения — в резервной копии: `cat ~/.local/state/bdi/backup-*/xfconf.txt`.

## Частые вопросы

**`check` пишет `система не из списка`.** Значит не Arch и не Void.
Проверка команд продолжит работать, но команду установки пакетов скрипт
не угадает — поставь их сам, по списку `FAIL`-строк.

**`FAIL nmcli`.** Без него вкладка Wi-Fi показывает «отключено» вместо
реального состояния. Остальное работает.

**`WARN шрифт Meslo Nerd Font`.** Иконки кнопок будут квадратами.
На Arch пакет `ttf-meslo-nerd` попадёт в строку «По желанию»; на Void в
индексе его нет, скачивать вручную.

**Сборка упала.** Смотри вывод выше последней строки — чаще всего не хватает
заголовков (`-dev`/`-devel` пакеты). `./install.sh check` покажет их в
разделе «Для сборки движка».
