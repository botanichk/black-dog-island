# Таймер на острове

Кнопка с песочными часами между часами и громкостью. Клик открывает небольшую
панель под островом (280 px по центру, не во всю ширину, как хаб).

Панель: крупный остаток шрифтом Bitcount над полем ввода и действия
(«Сброс», «Пауза/Продолжить», при звонке — «Стоп»). Цифры есть только когда
есть что показать: пока печатаешь — набранное, при отсчёте — остаток; в покое
строки нет и панель компактнее. Полоски прогресса и
пресетов нет — по слову владельца. Под действиями — строка звука: имя текущего
файла (клик — следующий звук, играет отрывок 3 с) и кнопка папки (открывает
`adapters/timer/sounds` в наутилусе).

Кнопка на острове сделана как соседняя громкость: тональная плашка, в ней
песочные часы и остаток теми же цифрами Bitcount. Клик по кнопке при звонке
глушит будильник, иначе открывает или закрывает панель
(`adapters/timer/click.sh`). Во время отсчёта плашка остаётся тональной, при
звонке становится `$error`.

Ширина острова — константа 619 px, поэтому на кнопке показывается `short`:
минуты без часов, не длиннее пяти знаков (`89:58`, а не `1:29:58`). Точный вид
`1:29:58` остаётся в панели. Плюс у цифр `min-width` под пять знаков, чтобы
плашка не меняла ширину от смены цифр. Место под кнопку взято у резерва трея
(было 140 px, стало 0): середину острова и так держит растяжка, иконки трея
просто занимают свободное место.

## Форматы ввода

| Ввод | Значение |
|---|---|
| `90` | секунды |
| `90s` | секунды |
| `6m` | минуты |
| `1h30m` | часы и минуты |
| `1:30` | 1 мин 30 с |
| `2:05:10` | 2 ч 5 мин 10 с |

Enter в поле запускает отсчёт. Пустая строка и мусор отвергаются.

## Состояния

`idle` → `run` → (пауза `pause`) → `ring` → `idle`.

Пока идёт отсчёт в панели есть «Сброс» и «Пауза»; на паузе — «Продолжить»;
при звонке — «Стоп» (глушит будильник и сбрасывает таймер).

## Почему так, а не как в плагине Noctalia

Плагин `~/.local/share/noctalia/plugins/timer-sound` считал секунды в
`update()` сервиса и держал флаг будильника в `/tmp`. Здесь взята только идея,
логика другая:

- **Отсчёт по метке конца, а не по счётчику.** В `~/.cache/eww-island/timer/end`
  лежит unix-время, когда таймер кончится. Поэтому отсчёт не зависит от того,
  открыта ли панель, жив ли Eww и сколько раз он перезапускался, и не копит
  ошибку.
- **Сторож в отдельном процессе.** Остров закрывается в полноэкранном режиме
  (`island-autohide.py`), вместе с ним замирает `defpoll`. Поэтому `start`
  запускает `timer.sh watch`: тот спит до конца и звонит сам. Метка конца
  сверяется — сброс, пауза или новый таймер отменяют звонок.
- **Флаг звонка — pid, а не `/tmp`-файл.** Цикл будильника пишет свой pid в
  `alarm.pid`; тик по нему отличает живой звонок от осиротевшего флага. У
  `pw-play` есть пауза между повторами, и проверка через `pgrep` в этот момент
  врала — будильник глох после первого проигрывания (поймано на 2-секундном
  таймере).
- **Звук не сдаётся при сбое.** Если `pw-play` не достал устройство, цикл не
  выходит, а повторяет через `paplay`/секунду паузы: будильник должен звенеть
  до «Стоп». Уведомление `notify-send` уходит сразу.

## Звуки будильника

Звук больше не прибит к коду: движок берёт файлы из `adapters/timer/sounds/`,
выбранный — имя файла в `~/.cache/eww-island/timer/sound`. Пусто или файл
пропал — первый по алфавиту. Поэтому добавить звук = положить файл в папку,
выбрать его кнопкой в панели (`sound-next`, играет отрывок 3 с). Подписи
`wav, oga, ogg, mp3, flac`.

Папку открывает `timer.sh open-sounds` через файловый менеджер по умолчанию
(`xdg-open`; если его нет - наутилус). У владельца xdg-open ведёт в наутилус,
но на другой машине откроется то, что человек выбрал сам.

В git из папки попадает только штатный `alarm.wav`: остальное закрыто в
`.gitignore` — владелец кладёт туда свои файлы, среди них попадались на 42 МБ.

## Файлы

```
adapters/timer/timer.sh        движок: start/pause/resume/reset/stop-sound/tick/watch/status/selftest/sound-next/sound-name/open-sounds
adapters/timer/click.sh        клик по кнопке: звенит - стоп, иначе панель
adapters/timer/sounds/         звуки будильника (alarm.wav из плагина, 6.6 с, 285 КБ); положить файл = добавить звук
~/.cache/eww-island/timer/     состояние: end, left, total, ringing, alarm.pid, sound
```

В `eww/eww.yuck`: `defpoll timer-state` (раз в секунду `tick`), кнопка на острове
и окно `panel-timer`. В `eww/eww.scss` — классы `.timer*` и `.tmr-*`.

## Шрифт

Цифры (на кнопке и в панели) — Bitcount Prop Single Roman. Шрифт не лежит в
репозитории, он должен быть установлен в системе (`fc-match "Bitcount Prop
Single Roman"`). В README зависимость ещё не описана.

## Проверка

```sh
adapters/timer/timer.sh selftest        # разбор времени и форматирование
adapters/timer/timer.sh start 3s
sleep 5; adapters/timer/timer.sh status # ждём "ring"
adapters/timer/timer.sh stop-sound
```

Замеры на этой машине: остров 619×50 в покое, при отсчёте на `1h30m`
(`89:58`) и при звонке; панель 280×215 с цифрами, 280×162 в покое, x=542
(центр острова 373+619/2).
Стык панели с островом — те же вогнутые углы 12 px, что у острова с верхом
экрана (`assets/corner-*.svg` в слое overlay). Нижние углы острова при открытой
панели таймера остаются круглыми: `panel-open.sh` не считает `panel-timer`
панелью во всю ширину.

## Ограничения

- Будильник один. Второй таймер заменяет первый (так же было в плагине).
- Таймер не переживает перезагрузку: метка конца в `~/.cache` очищается.
- Пауза не ставит будильник на паузу — звонок просто не наступает, пока нет
  метки конца.
- Плагин Noctalia и его файлы не тронуты; этот таймер с ним не связан.
