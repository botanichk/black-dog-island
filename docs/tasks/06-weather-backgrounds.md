
## Дополнение после просмотра preview.png (владелец)
Сцены хорошие, пересоздавать не нужно. Но яркость неравномерная:
1. Индивидуальное затемнение по виду (переменная w-shade из forecast.sh, число 0.30-0.65 для
   rgba(0,0,0,<alpha>) в :style). Измерить среднюю яркость левых 55% каждой картинки после
   ресайза (`magick img.jpg -crop 55%x100%+0+0 +repage -colorspace Gray -resize 1x1 txt:-`),
   подобрать alpha так, чтобы средняя яркость под текстом после затемнения была не выше 20-25%
   (контраст с белым текстом). Светлые сцены (fog-day, snow-day, cloud-day, partly-day, clear-day,
   молнии в storm) получат alpha выше, тёмные ночные ниже. Таблицу "вид -> alpha -> яркость
   до/после" показать в отчёте.
2. Позиция фона: `background-position: 75% 50%` (герои справа), чтобы при обрезке по краям
   фонарь и Жулик не уходили. Проверить, что cover не обрезает героя при пропорциях карточки
   1.5:1 и 2:1 (расчётом по размерам окна и картинки, показать числа).
3. Иконка погоды (cond-*.svg) остаётся, но проверить, что она читается на каждом из 16 фонов
   (цвет иконки в левой части против фона), если не читается, добавить ей тонкую тень/подложку.
4. Водяной знак: самое нижнее 8% по высоте обрезается целиком (на образце Qwen был в правом
   нижнем углу). Если на каком-то из 16 файлов знак оказался выше (по цвету пикселей справа внизу
   нестандартная светлая зона), сообщить имя файла.
