# Шаг 4: кнопка обоев на острове (docs/SPEC-hub.md, шаг 4)
Только это. Модель не принимает картинки: проверять текстом.
1. Проверить без установки: `command -v xfdesktop-settings nitrogen waypaper variety feh`.
   Рабочий стол рисует xfdesktop, нужна утилита, которая ставит обои через xfconf.
   По умолчанию xfdesktop-settings. Другую не ставить без разрешения владельца.
2. Кнопка на острове: иконка Meslo Nerd Font (label), стиль и hover как у соседних,
   запуск отвязанно (`setsid -f ... >/dev/null 2>&1`), команда запуска в одном месте.
3. Запуск не плодит копии: если окно утилиты уже открыто, поднять его (`wmctrl -a`).
4. Ширина острова остаётся ровно 619: место берётся из растяжки. Замер до и после.
5. `eww --config eww reload` без ошибок, замер острова (373 0 619x50) и хаба.
   Клик агент не проверит: "владельцу проверить глазами". Один коммит.
