# Вкладка "Медиа": что играет и управление плеером (стандарт MPRIS)
Модель не принимает картинки: проверять текстом. Один шаг, один коммит.
Закон хаба: вкладка заполняет область справа от колонки по ширине и высоте.
Правило "Сеть и связь" из AGENTS.md в силе. Реальное воспроизведение владельца
не запускать и не останавливать при тестах: управление проверять заглушкой или
"владельцу проверить глазами".

## Сначала проверка без правок
1. `command -v playerctl`; `busctl --user list | grep -i mpris` при запущенных плеерах
   (Marsik FM, Firefox с видео, PortProtonQt). Какие плееры видны.
2. Для каждого видимого: `busctl --user introspect org.mpris.MediaPlayer2.ИМЯ /org/mpris/MediaPlayer2`
   и свойства Metadata, PlaybackStatus, Position, CanSeek, CanControl.
3. Отдаёт ли Marsik FM MPRIS? Если нет, остановиться и написать об этом: правка в проекте
   радио, не здесь. Остальное можно проверять на Firefox или другом плеере.
4. Пакеты не ставить без разрешения. Если playerctl нет, реализовать через busctl/gdbus,
   (`busctl --user call ... org.mpris.MediaPlayer2.Player PlayPause`), записать, чего это стоит.
   Предложить playerctl как возможное улучшение, не ставить.

## Адаптер adapters/media/mpris.sh
1. Выбор плеера: играющий (Playing), иначе последний активный, иначе первый в списке.
   Ключи: `player` (имя), `status` (playing/paused/stopped/none), `title`, `artist`, `album`,
   `art` (путь к локальной миниатюре, см. ниже), `pos`, `len` (секунды), `json` (всё сразу).
2. События вместо опроса раз в секунду, если можно (`dbus-monitor` на PropertiesChanged или
   `playerctl --follow`); иначе опрос не чаще 1 с. Выбрать и объяснить в отчёте.
   Нагрузка: `top -bn1 | head` до и после, без заметного роста.
3. Обложка (mpris:artUrl): file:// - использовать; http(s):// - скачать один раз в
   ~/.cache/eww-island/art/, имя по хэшу URL, ужать до 200x200 (`magick`), таймаут 5 с,
   без скачивания в цикле. Нет обложки - значок-заглушка из Meslo Nerd Font. Eww кэширует
   картинку по пути: имена с хэшем, чтобы смена трека обновляла картинку.
4. Любое значение из плеера (название, исполнитель) в строку :onclick или в команду shell
   не подставлять. Кавычки, `$()`, `;`, эмодзи, очень длинные названия должны работать
   (обрезка, ellipsis). Проверить заглушкой с такими строками.

## Вкладка
1. Иконка ноты (Meslo Nerd Font) в колонке вкладок после "Главной"; defvar hub_tab принимает "media".
2. Слева крупная обложка (квадрат, скруглена), справа: название, исполнитель, альбом,
   ниже ползунок позиции и время "1:23 / 4:56", ряд кнопок: предыдущий, пауза/играть, следующий.
   Всё заполняет окно по ширине и высоте.
3. Пустое состояние: плееров нет - надпись "Ничего не играет" по центру, кнопки неактивны.
4. Ползунок позиции: двигается по ходу трека, не дёргается при перетаскивании, перемотка
   через Seek/SetPosition только если CanSeek истинно (иначе ползунок только показывает).
5. Несколько плееров: переключатель "Плеер: Имя" (по клику следующий). Выбор запоминается,
   пока плеер жив.
6. Кнопки запускать отвязанно (`setsid -f`), команда кнопки знает только имя действия
   (prev, playpause, next, seek <секунды>), не данные трека.
7. Если плеер закрылся посреди работы: вкладка не падает, показывает пустое состояние.

## Не менять
Ширину и положение острова (373 0 619x50), хаб (y=50), стык, остальные вкладки,
порядок кнопок на острове.

## Приёмка
- `eww --config eww reload` без ошибок разбора, замер острова и хаба до и после.
- Адаптер из терминала на реальных плеерах: вывод каждого ключа показать (чтение можно).
- Заглушка с "тяжёлыми" строками в названии - вкладка не ломается, onclick чистый.
- "Владельцу проверить глазами": трек из Marsik FM виден, пауза/следующий/перемотка,
  обложка меняется со сменой трека, пустое состояние, переключение плеера.
- Один коммит. Дату брать из `date`.
