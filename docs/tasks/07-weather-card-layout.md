# Верхняя карточка погоды: без иконки, текст в левом верхнем углу
Модель не принимает картинки: проверять замерами и кодом. Один шаг, один коммит.

## Что сделать
1. Убрать из верхней карточки иконку погоды (cond-*.svg) вместе с тёмной подложкой и любые
   другие глифы на фоне. Фоновая картина должна быть видна целиком.
   Иконки в списке прогноза справа НЕ трогать.
2. Текст прижать к левому верхнему углу карточки, одним столбцом:
   температура крупно (около 44 px, жирная), под ней описание ("Небольшой дождь"),
   под ним диапазон дня ("3...4°"). Отступы от углов карточки одинаковые, около 16 px.
   Диапазон дня справа внизу убрать, он теперь в этом столбце.
3. Читаемость: тонкая тень текста (`text-shadow`, если GTK3 в нашей сборке её применяет,
   иначе сказать прямо) и мягкий боковой градиент затемнения слева направо
   (`linear-gradient(90deg, rgba(0,0,0,.45), rgba(0,0,0,0) 60%)`) отдельным слоем поверх
   картинки, но под текстом. Не затемнять правую часть, там герои.
4. Левый верхний угол теперь главный: измерить яркость зоны под текстом (левые 40% по ширине,
   верхние 55% по высоте) для всех 16 фонов, добавить в таблицу "вид -> яркость до/после".
5. Нижняя карточка и колонка прогноза не меняются. Размеры окна острова и хаба те же.

## Приёмка
- `eww --config eww reload` без ошибок разбора, замер острова (373 0 619x50) и хаба до и после.
- Таблица яркости, git status чистый, один коммит.
- "Владельцу проверить глазами": текст читается на всех 16 фонах, герои не закрыты.

## Уточнение владельца
Глиф и подложку убрать только с картинки верхней карточки, на всех 16 фонах (карточка одна, вид
фона меняется переменной). Значки дней в списке прогноза справа, иконки вкладок и остальные глифы
хаба не трогать.
