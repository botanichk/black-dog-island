## Шаг 1. Выбор акцента (отдельный коммит)
Для любой выбранной палитры (встроенной, сообщества, из обоев) в вкладке "Цвета" ряд из трёх круглых
образцов "Акцент": primary, secondary, tertiary палитры. Клик меняет роль primary острова на выбранный
цвет. on_primary, primary_dim и прочие производные считаются существующей логикой контраста
(palette_lib), текст на акценте читаем (контраст не ниже 4.5:1, показать числа). Выбор хранится в файле
theme/accent (вне git) и сохраняется при смене палитры там, где у палитры есть такой акцент. По умолчанию
primary, как сейчас: без выбора внешний вид не меняется.

## Шаг 2. Каталог сообщества (отдельный коммит)
Конвертер формата mPrimary/mSecondary/... в наши схемы (общий код с palette2scheme.py, не дублировать).
Во вкладке отдельный раздел "Сообщество" под встроенными: карточки по три в ряд, имя (urldecode),
образцы surface и акцента, прокрутка внутри вкладки. id с префиксом c-<слаг>. Битый файл пропускается
с сообщением в stderr, остальные остаются. Режим dark/light берётся из theme/mode. Список строится
из каталога, не копируется в репозиторий. Если каталога нет, раздел не показывается, и вкладка не падает.
Необязательно: фильтр по оттенку акцента (все / синие / зелёные / тёплые / серые).

## Шаг 3. Схемы для обоев (отдельный коммит)

3. Если noctalia theme принимает исходный цвет: добавить "пипетку" из 5-6 главных цветов картинки

## Уточнение к шагу 3.1 (подтверждено владельцем)
При /backdrop/single-workspace-mode=true xfdesktop показывает на всех столах обои стола
/backdrop/single-workspace-number (у владельца вероятно 2: "Чёрный пёс на острове.png", а у стола 0 лежит "буря.jpeg").
from-wallpaper.sh сейчас берёт обои ТЕКУЩЕГО стола: на столе 0 он читает "бурю", которой на экране нет.
Правило: single-workspace-mode=true -> ключ стола single-workspace-number (проверить, что такое свойство есть
в xfconf: `xfconf-query -c xfce4-desktop -l | grep single`); иначе обои текущего стола.
То же правило применить в --name и в кнопке "С обоев" вкладки. Проверка: wmctrl -s 0 и wmctrl -s 2,
--name возвращает одно и то же имя, совпадающее с картинкой на экране.

## Результат шага 3.1 (18.11, коммит в этой же правке)
Причина расхождения подтверждена замером: на экране был «Чёрный пёс на острове.png»
(полоса y=4..46 совпала с Δ=3), а скрипт печатал «буря.jpeg» со стола 0.
`/backdrop/single-workspace-mode = true`, `/backdrop/single-workspace-number = 2`.
Правка: `from-wallpaper.sh` при включённом режиме берёт номер стола из
`single-workspace-number`, иначе текущий. `--name` и кнопки «С обоев» наследуют
правило (имя приходит из того же скрипта).

Проверено:

- Режим выключен (подмена `xfconf-query` в PATH): стол 0 -> «буря.jpeg», стол 2 ->

  `#0e1416` / `#82d3e1`). Замер острова: `(690,20) = 0f1417` совпал, primary
