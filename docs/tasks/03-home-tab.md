# Вкладка "Главная" (home): быстрые настройки, как у Noctalia
Модель не принимает картинки: проверять текстом. Один шаг, один коммит.
Закон хаба: вкладка заполняет область справа от колонки по ширине и высоте.

## Сначала проверка без правок
`command -v brightnessctl pactl bluetoothctl nmcli`, `ls /sys/class/backlight/`,
`brightnessctl -l`, `id` (группа video), запись в brightness без sudo.
Если яркость недоступна, остановиться и написать, что именно не так. Не ставить пакеты
и не менять права без разрешения владельца.

## Состав
1. Колонка вкладок: домик первым (иконка Meslo Nerd Font), вкладка в stack, defvar hub_tab
   принимает "home".
2. Верхний ряд плиток-переключателей на всю ширину, состояние подсвечено ($primary):
   - Wi-Fi: `nmcli radio wifi on|off`, состояние `nmcli radio wifi`;
   - Bluetooth: `bluetoothctl power on|off`, состояние `bluetoothctl show | grep Powered`
     (если rfkill блокирует, написать);
   - Звук: `pactl set-sink-mute @DEFAULT_SINK@ toggle`.
3. Два ползунка (scale) во всю ширину: громкость (`pactl set-sink-volume`, 0-100)
   и яркость (`brightnessctl set N%`, минимум 5%, чтобы экран не гас). Справа число в процентах.
   Ползунок не дёргается при перетаскивании: описать, как решено.
4. Блок системы с полосками: CPU (EWW_CPU), RAM (EWW_RAM), температура (EWW_TEMPS),
   батарея (EWW_BATTERY) со значком зарядки. Интервалы не чаще 2 с.
5. Состояния плиток и ползунков обновляются и при внешнем изменении (громкость колесом
   или клавишей), не реже раз в 2 с. Скрипты в adapters/x11/ или adapters/system/.
6. Необязательно, отдельным коммитом: клик по батарее на острове открывает хаб на "home".
   Ширина острова не меняется.

## Приёмка
- `eww --config eww reload` без ошибок, замер острова (373 0 619x50) и хаба до и после.
- Каждый скрипт проверен из терминала: чтение и запись, вывод показан.
- Нагрузка: `top -bn1 | head` до и после, без заметного роста.
- Клики и ползунки агент не проверит: "владельцу проверить глазами".
