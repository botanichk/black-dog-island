# Eww Island (X11) - правила для агентов
Остров в стиле Noctalia на Eww поверх XFCE (xfwm4, композитинг, без picom),
экран 1366x768. Панель XFCE отключена, Plank снизу не трогать.

## С чего начинать сессию
1. `git log --oneline | head -10`, `git tag`
2. docs/SPEC-hub.md (хаб, текущий этап), docs/SPEC-tray.md (трей, сделан)
3. `wmctrl -lG | grep 'Eww - '` и `timeout 3 build/target/release/eww --config eww logs | tail`
4. Кратко сказать владельцу план, потом делать по одному шагу.

## Структура
eww/ (eww.yuck, eww.scss, assets/), adapters/ (shell и C, вывод в stdout),
scripts/ (build-eww.sh, run-island.sh, stop-island.sh), patches/ (патчи на Eww),
docs/ (спеки и отчёты). Пакет eww из репозитория не подходит: он старый,
нужна наша сборка build/target/release/eww с патчами.

## Константы (не менять без согласия владельца)
- Окно острова: dock, x=373, y=0, ширина ровно 619 px, высота 50. Ширина
  не зависит от содержимого: min-width плюс растяжка `(box :hexpand true)`.
- Резерв сверху `:reserve (struts :side "top" :distance "50px")`.
- Автоскрытие (`adapters/x11/island-autohide.py`) прячет остров только когда
  активное окно в `_NET_WM_STATE_FULLSCREEN` (игры, фильмы): `eww close island`;
  при выходе из полноэкранного режима остров открывается и центрируется сам.
  Обычные и развёрнутые окна остров не трогают. События - `xprop -spy`,
  состояние «скрыт» - файл `~/.cache/eww-island/autohide-hidden`.
- Остров открывается СРАЗУ по центру: позиция передаётся в самом `eww open
  --pos <x>x0`, а не вторым вызовом после замера. Ширина берётся из
  `~/.cache/eww-island/island-width` (пишут и `run-island.sh`, и демон), при
  отсутствии - константа 619. Иначе окно на кадр рождалось в x=0 и прыгало
  вправо; после замера ширина всё равно сверяется и кэш правится.
- Хаб и панели: x и ширина как у острова (берёт adapters/x11/panel.sh из
  `wmctrl -lG`), y=50. Заголовок окна обязан начинаться с "Eww - panel-":
  по нему adapters/x11/panel-open.sh делает нижние углы острова прямыми.
- Верх панели прямой, низ скруглён (18 px), цвета только из переменных SCSS.
- Закон вкладок хаба: любая вкладка заполняет область справа от колонки
  вкладок по ширине и высоте (`:hexpand true :vexpand true` по всей цепочке),
  размер окна от вкладки не зависит.

## Жёсткие запреты
- Не трогать build/target, build/eww-src, Plank. Изменения Eww только через
  patches/*.patch и scripts/build-eww.sh.
- Не переписывать eww.yuck и eww.scss целиком, только точечные правки.
- Не ставить пакеты без разрешения владельца: сначала список, потом вопрос.
- Не менять ширину острова, радиусы и стык.

## Проверка
- Модель не принимает изображения. Снимки экрана НЕ открывать через read и
  не прикладывать: сессия падает (error: image_url unsupported).
- Проверять только текстом: `wmctrl -lG`, `eww logs`, цвет пикселей
  `import -window root -crop 1x1+X+Y +repage txt:-`. В отчёте писать
  "владельцу проверить глазами: ...".
- Не кликать мышью, не переключать окна и рабочие столы во время проверки:
  владелец работает рядом, замеры собьются.
- Окно хаба и панелей применяет `eww reload`. Окно острова, его резерв
  и ширину: scripts/stop-island.sh, затем scripts/run-island.sh.
- После правки: `eww logs` без ошибок, замер острова и хаба, три основные
  панели по-прежнему стыкуются с островом без ступенек.
- Лог Eww общий для запусков: смотреть только строки новее начала сессии
  (run-island.sh чистит лог при старте демона).

## Ограничения GTK3 CSS
Нет flex, grid, keyframes, backdrop-filter, clip-path. `transition` есть.
`min-width` у меню (GtkMenu) игнорируется, у box и label работает.
Вогнутые углы только через SVG. Eww пакует иконки трея в EventBox с expand,
ужать подсветку можно только патчем.

## Git
Один шаг - один коммит, сообщение по-русски. Перед рискованной правкой
коммит текущего состояния. Тег ставит владелец (stage5-ok, stage6-ok...).

## Отчёт
Дату брать из `date`. Писать по-русски без смешения языков, только то,
что реально запускалось, с выводом команд. Не получилось - сказать прямо,
не обходить молча. Не выдумывать даты, номера коммитов и результаты.

## Известные пробелы
Вкладка Wi-Fi пока без управления: нет выключателя, ввода пароля,
подключения к новым сетям (connect работает только для сохранённых).
Делать только по отдельной спеке.

## Обои
Кнопка обоев на острове запускает выбор шестиугольниками (hypr-wallpicker
из `~/src/hypr-wallpicker`), под сеткой лежат те же обои, размытые и
затемнённые на 40 % (`-b`, `--blur 16`, `--scrim 40`). Хук
`adapters/wallpicker/apply.sh` ставит обои через xfconf;
`xfdesktop-settings` остался запасным путём. Правило выбора стола
(single-workspace-mode) живёт в `theme/desktop.sh` - одно на всех.
См. docs/WALLPICKER.md.

## Plank
Рамка дока берёт цвет из `$primary` острова: `theme/plank.sh` собирает тему
`EwwIsland` (копия исходной с одной изменённой строкой OuterStrokeColor) и
перезапускает Plank, потому что тот не перечитывает тему на лету. Вызов -
последний шаг `theme/apply.sh`. Правку заливки и остального не делаем.
См. docs/PLANK.md.

## Доска задач
Начало сессии: прочитать docs/TASKS.md. Конец каждого шага: обновить его одной строкой (раздел
"Журнал", и перенести пункт между разделами), закоммитить вместе с шагом. Решения владельца
из раздела "Решения" не нарушать. Спеки без слова владельца не писать.
